
# Controller map

MARS supports Xbox and PS controllers by assigning them to a common controller map. This can be used trough the next import:

```java
import com.stzteam.mars.operator.ControllerOI;
```

 The mapping goes as follows:

## ActionButtons

| In code name | Xbox | PS5 |
|--------------|------|-----|
| bottom       | A    | ✕ (Cross) |
| right        | B    | ○ (Circle) |
| left         | X    | □ (Square) |
| top          | Y    | △ (Triangle) |

## DPadTriggers

| In code name | Xbox | PS5 |
|--------------|------|-----|
| up           | DPad Up    | DPad Up |
| down         | DPad Down  | DPad Down |
| left         | DPad Left  | DPad Left |
| right        | DPad Right | DPad Right |

## Bumpers

| In code name | Xbox | PS5 |
|--------------|------|-----|
| left         | LB   | L1 |
| right        | RB   | R1 |

## SpecialTriggers

| In code name | Xbox | PS5 |
|--------------|------|-----|
| back         | View / Back | Share |
| start        | Menu / Start | Options |

## AnalogTriggers

| In code name | Xbox | PS5 |
|--------------|------|-----|
| left         | LT   | L2 |
| right        | RT   | R2 |

## AnalogAxis

| In code name | Xbox | PS5 |
|--------------|------|-----|
| left         | LT axis | L2 axis |
| rigth        | RT axis | R2 axis |

## Stick

| In code name | Xbox | PS5 |
|--------------|------|-----|
| left.x       | Left Stick X | Left Stick X |
| left.y       | Left Stick Y | Left Stick Y |
| right.x      | Right Stick X | Right Stick X |
| right.y      | Right Stick Y | Right Stick Y |
